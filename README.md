# Adaptive Bilingual Learning Platform

## Project Purpose and Pilot Objectives

This pilot project explores an adaptive bilingual learning system that personalizes educational content based on student knowledge and language proficiency. The platform aims to demonstrate how AI can assist learning decisions while maintaining human oversight and control.

## Core Principle: "AI assists, humans decide."

All recommendations, routing decisions, and mastery estimates generated by the system are presented as suggestions that qualified human educators can review, modify, or override. The system never makes final decisions about student learning paths without human validation.

## Selected Pilot Source: Google Machine Learning Crash Course (MLCC)

The pilot uses concepts and frameworks from the Google Machine Learning Crash Course as the foundational ML education source. Selected MLCC modules inform the knowledge modeling, adaptive routing, and evaluation methodologies.

## Proposed Pilot Scope

- **In Scope:** Knowledge concept graph construction, basic adaptive routing based on prerequisite dependencies, bilingual UI language switching, ethics and consent framework, and MLCC-informed evaluation metrics.
- **Out of Scope:** Full-scale student data processing, confidential assessment data, automated grading, or any system that makes irreversible decisions about student progression without human review.

## Planned Workstreams

1. **Knowledge Modeling** - Concept taxonomy, prerequisite graph construction, mastery state representation
2. **Backend and Data** - API design, data pipeline, state management, MLCC-aligned evaluation
3. **Ethics and Consent** - Data privacy, informed consent processes, bias mitigation, human-in-the-loop governance
4. **Bilingual UI** - Language selection, dual-language content presentation, locale-aware adaptive routing
