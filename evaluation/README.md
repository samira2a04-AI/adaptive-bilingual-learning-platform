# Evaluation Directory

Evaluation framework and metrics for the adaptive bilingual learning platform.

**Primary Metrics:** AUC (Area Under ROC), Accuracy, Log Loss - aligned with MLCC evaluation practices.

**Evaluation Components:**
- Knowledge tracing model performance
- Adaptive routing effectiveness
- Bilingual UI usability pilot studies
- Bias and fairness assessments

**Workstream:** Partners with backend data pipeline and ethics workstream for responsible evaluation.
