# Data Directory

Contains dataset descriptions, formats, and provenance tracking for the adaptive bilingual learning platform.

**Datasets Used:**

| Dataset | Domain | Size | Purpose | Link |
|---|---|---|---|---|
| ASSISTments 2009-2010 | Education (Math) | ~1M interactions | BKT model training, evaluation | https://www.assistments.org/ |
| EdNet-KT1 | Education (All subjects) | ~4M interactions | Large-scale KT model training | https://ednet-data.org/ |
| Junyi-KT | Education (China) | ~500K interactions | Cross-cultural validation | https://junyi.ac/ |

**Important:** No student data is committed to this repository. Placeholder for dataset descriptions, formats, and provenance tracking.

**Data Privacy:** Per ethics framework - all data encrypted at rest and in transit. Environment variables for credentials. No raw dataset files in repository (per .gitignore).

**Data Workstream:** See backend for data pipeline and ethics for data privacy considerations.
